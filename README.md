# Deepak Kumar Shukla — Cinematic AI/ML Portfolio

A self-contained portfolio designed for GitHub Pages and a custom `.me` domain.

## Included
- Deepak's profile photo and downloadable PDF resume
- Light / Dark / Red / Yellow / Cyan / Aurora / All Colors modes
- Cinematic spotlight, film-scan and 3D-style effects
- Welcome greeting with browser speech synthesis
- Female English voice preference when the browser provides one
- Farewell greeting for external navigation
- IIT Delhi and IIT Roorkee Campus Ambassador experience
- CodSoft AI internship
- Project explanations and supplied GitHub project links
- Certificate gallery with full-screen preview
- Birthday section for 29 March 2003
- Local portfolio AI assistant (no API key)
- Visitor suggestion box using localStorage + optional email handoff
- GitHub Pages / Hostinger-friendly static files

## Run locally
Open `index.html` in Chrome/Edge/Firefox.

## GitHub Pages
Upload the contents of this folder to your repository root and enable GitHub Pages from the repository's Pages settings.

## Custom Hostinger `.me` domain
After GitHub Pages is working, point the domain's DNS records at GitHub Pages and configure the custom domain in the repository's Pages settings.

## Important note about project links
The Recommendation System and Face Recognition links supplied for this portfolio point to GitHub files. They are shown as project/source links, not as a falsely claimed live demo.
